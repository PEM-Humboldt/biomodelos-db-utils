API

Subcomando para configurar la conexión a la API de BioModelos. Esta configuración es obligatoria para la ejecución de otros comandos.

Parámetros

Usage: bmdbutils setup api [OPTIONS]

  Comando para configurar el API de BioModelos.

  Ejemplo de uso: $ bmdbutils setup api --url http://localhost:4000

Options:
  --url TEXT  URL del API de BioModelos (incluyendo el protocolo http o https
              y el número del puerto)  
  --help      Show this message and exit.

Consideraciones

  • Una vez realizada la configuración inicial de este subcomando, no es necesario ejecutarlo de nuevo.

Comportamiento del subcomando

  • Guarda la configuración para la conexión a la API para ser utilizada por otros comandos de bmdbutils.
  • Sobrescribe la configuración existente si ya ha sido definida previamente.
  • No valida la disponibilidad del API en el momento de la ejecución.

Valores por defecto

  • --url: http://localhost:4000.

Validaciones

  • La URL debe contener el protocolo (http, https, etc), de lo contrario puede interpretar erróneamente el puerto.
  • Todos los parámetros son obligatorios si no existe una configuración previa.
